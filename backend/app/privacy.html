Frame to Issue

Privacy Policy

Effective September 23, 2026

Overview

Frame to Issue helps you capture part of a webpage, annotate it, and create an issue in a GitHub repository you choose.

The extension processes captures on your device and sends issue content directly to GitHub only when you submit it. The Frame to Issue sign-in service handles the OAuth exchange needed to connect your GitHub account. It does not receive your screenshots or issue content.

Information the extension processes

When you use Frame to Issue, the extension may process:

  • The region of the visible webpage you select, including any information visible in that region.
  • Your annotations, issue title, optional description, selected repository, page URL, capture date and time, browser window dimensions, and page viewport dimensions.
  • Your GitHub username, repositories available to your account, recent repository choices, and GitHub OAuth access and refresh tokens.

Capture drafts, form drafts, repository preferences, and GitHub session credentials are stored in Chrome extension storage on your device. Chrome prevents ordinary webpages from reading this storage. A new capture replaces the previous capture and its form draft. A successfully submitted issue clears its capture draft and temporary upload information. Signing out clears your stored GitHub session credentials.

How information is used and shared

The extension uses your information only to provide the capture-to-issue workflow:

  • GitHub receives your screenshot, issue title, description, capture context, and selected repository when you submit an issue. GitHub also provides your username and eligible repository list after you sign in.
  • The Frame to Issue sign-in service exchanges GitHub authorization codes and refresh tokens so the extension can maintain your signed-in session.
  • Railway hosts the sign-in service, and Neon hosts its temporary OAuth database.

Frame to Issue does not sell your personal information, use it for advertising, or use analytics or tracking technologies. It does not use your data to determine creditworthiness or for lending purposes.

OAuth security and retention

The sign-in service requests GitHub's repo permission so you can list repositories and create issues with screenshot attachments in public or private repositories you can access.

During sign-in, the service stores a one-time authorization attempt containing security verification values for up to 10 minutes. After GitHub authorizes access, it stores the returned token set in an encrypted, one-time ticket for up to 60 seconds while the extension redeems it. These records become unusable when redeemed or expired and are removed during redemption or routine cleanup. A refresh token passes through the sign-in service when a session is renewed, but the service does not intentionally retain it after responding.

Your choices and controls

  • You choose the screen region to capture, the annotations and text to include, the repository, and whether to submit.
  • You can sign out inside the extension to remove its locally stored GitHub credentials.
  • You can remove the extension or clear its extension data in Chrome to delete remaining local drafts and preferences.
  • You can revoke Frame to Issue in your GitHub account settings to end its GitHub access.
  • You can manage or delete submitted issues and attachments through GitHub, subject to your repository permissions and GitHub's policies.

Security

Frame to Issue uses HTTPS, a proof-bound OAuth flow, short-lived one-time exchange records, and encryption for token tickets stored by the sign-in service. No system can guarantee absolute security, but we limit processing to what is needed for the product to work.

Children

Frame to Issue is a productivity tool for GitHub users and is not directed to children under 13. We do not knowingly collect personal information from children.

Changes to this policy

We may update this policy as the product changes. The effective date at the top will identify the latest version. Material changes will be reflected here before they take effect.
